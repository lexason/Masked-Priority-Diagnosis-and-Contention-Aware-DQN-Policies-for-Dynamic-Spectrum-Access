# Prospective collision-aware study

This installable module contains the source-frozen collision-aware experiment
for “Masked-Priority Diagnosis and Contention-Aware Evaluation of Deep Q-Network Policies for Dynamic Spectrum Access”. It contains 12,672 aggregate evaluation
records and 60 prospective checkpoints. It contains no slot-level collision
records.

The local `pyproject.toml` package allowlist is restricted to the `main`
package so `uv sync --frozen` does not refer to repository packages that are
not part of this archive. Two absolute temporary-path literals in one planning
test are expressed through an equivalent path constructor so public privacy
scans remain path-neutral. `SOURCE_PORTABILITY_REPAIRS.json` pins the original
and public source identities. These packaging repairs do not change
experimental logic, checkpoints, aggregate records, protocol freezes, or
result seals.
